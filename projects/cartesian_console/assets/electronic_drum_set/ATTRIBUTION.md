# Electronic Drum Set

This work is based on "Electronic Drum Set" by SINNIK, licensed under CC BY 4.0.

- Model: https://sketchfab.com/3d-models/electronic-drum-set-51b95e62da844b95b6ca871c23b6e858
- License: https://creativecommons.org/licenses/by/4.0/

The downloaded archive includes the author's original `license.txt`. Conversion preserves that file alongside the generated assets. Modifications for this project include coordinate conversion, OBJ export, material parameter conversion, and fitted collision disks for the six selected pad meshes. Scene placement is configurable.

The source archive and converted geometry are stored under `.work/drumset/`; they are not included in Git. The import command regenerates them from the downloaded archive. The original archive contains a stool normal map; the current renderer uses imported mesh normals, base colors, metallic values, and roughness values.
